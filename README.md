# O Launcher

A touch-friendly Android launcher project for Minecraft: Java Edition.

## Status

**Early development — UI foundation only.** The current app is a launcher prototype. It does not yet authenticate Minecraft accounts, download game files, provision a Java runtime, or launch Minecraft.

## Roadmap

1. Android project foundation and CI
2. Launcher UI and local profile/version management
3. Microsoft authentication and Minecraft entitlement checks
4. Version manifest, assets, libraries, and client downloads
5. Android-compatible Java runtime and rendering integration
6. Game lifecycle, touch controls, and storage
7. Mod-loader support, testing, and release packaging

## Stack

- Kotlin, Jetpack Compose, Gradle Kotlin DSL
- Android SDK
- GitHub Actions

## Build

Open in a recent Android Studio version with JDK 17 and Android SDK 36 installed, then build the `app` module.
